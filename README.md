# Otomatik-Siparis
2022 Lisans tezi projesi için geliştirilmiştir.

Proje kurulduktan sonra veritabanında tüm table'lar a girdi eklenmesi gerekir.
Ürünler Sayfasından sahip olunan ürünler , ürünlerin istenilen sayısı ve limitleri belirlenmelidir.
Belirlendikten sonra barkodda okuma işlemleri yapılabilir.
